# Privacy Policy

**Last updated:** 2026-09-13

This Privacy Policy explains how **[server owner or community name]** handles information used by the Valheim Discord bot (the "Bot").

The Bot is intended only for use on private Discord servers and private Valheim communities. It is not intended for public, open-access, or commercial deployment.

## Information We Use

The Bot may process:

- Your Discord user ID and display name.
- Discord messages sent as Bot commands.
- Valheim player names and server status information.
- Technical logs needed to operate and troubleshoot the Bot.

Please do not send passwords, payment details, or other sensitive information to the Bot.

## How We Use Information

Information is used only to:

- Check whether a user is authorized to run commands.
- Execute approved Valheim server commands.
- Send server status and command results to Discord.
- Maintain, secure, troubleshoot, and moderate the server.

## Sharing and Storage

Information may be visible to server administrators and in Discord channels where the Bot posts messages. We do not sell personal information.

The Bot may retain command and server logs for as long as reasonably necessary for operation, security, moderation, and troubleshooting.

## Your Choices

You can stop using the Bot at any time. To request removal of your Discord user ID from the authorized-user list or ask a question about your information, contact the server administrators.
